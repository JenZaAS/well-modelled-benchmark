- Name: MIT

- Restrictions: none. All code in `workstreams/black_physics/` is original code written for this repository.

The models implement published equations (Gardner et al. 1974; Castagna et al. 1985; Greenberg & Castagna
1992; Wyllie et al. 1956; volumetric density mixing; a constant Vp/Vs ratio). Papers and coefficient sources
are credited in each model card under [`models/`](models/). No third-party code, weights or data are included.
Each model folder repeats this notice in its own `LICENSE.md`, and every contender class sets
`licence_name`, `licence_url` and `licence_restrictions`.

Users and agents must verify the licence fits their use before running or redistributing a model.
